# ATKInventory
Visual Studio, SQL Server Management Studio, ASP.NET Core Web API controller menggunakan .NET 10 LTS dan ADO.NET , C# Windows Forms (.NET FRAMEWORK), dan ADO.NET.

Cara membuat database dari script SQL:
buatlah database ATKInventoryDB
Lalu jalankan query ATKInventoryQUERY.sql bagian create table, dan tambahkan constraint
buat connection string lalu pasang di visual studio.
